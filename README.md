🎮 Jogo Pedra, Papel e Tesoura

Este projeto é uma aplicação interativa do clássico jogo Pedra, Papel e Tesoura, desenvolvida com JavaScript, manipulando elementos do DOM para atualizar placar, exibir escolhas e mostrar o resultado em tempo real.

🚀 Funcionalidades

Geração aleatória da jogada da máquina

Comparação lógica entre as escolhas

Atualização dinâmica do placar

Exibição visual das escolhas com emojis

Manipulação de elementos HTML via querySelector

🧠 Conceitos aplicados

Funções com retorno

Estruturas condicionais (if / else)

Manipulação do DOM

Arrays e objetos

Geração de números aleatórios com Math.random()

🎯 Objetivo do projeto

Praticar lógica de programação e reforçar conceitos fundamentais de JavaScript, especialmente interação com a interface e controle de estado da aplicação.
